# 🛡️ HFL Razbloker Client

Standalone Windows Client for **In-Flight Transparent DNS Redirection** and **Custom Local Domains (.local / .internal)**.

## 🚀 Features
- ⚡ 100% C# .NET 9 WPF UI (Cyberpunk Dark Glassmorphism)
- 🔒 In-flight transparent DNS interception using WinDivert (no Windows network adapter / DHCP changes)
- 🌐 Native .local and .internal domain resolution directly to the server
- 🔑 Hardware ID (HWID) license binding and automatic SSL certificate trust installation
